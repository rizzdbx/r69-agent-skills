# R69 Labs Agent Skills

Marketplace-ready `SKILL.md` packages for the R69 Labs agent-commerce stack.

## Skills

- `pyrimid-protocol` — discover paid AI/API products, route x402 USDC purchases on Base, list vendor endpoints, and earn affiliate commissions.
- `mya-launchpad` — find agent earning opportunities, browse bounties/jobs/swarms, and connect agents to monetization paths.
- `agentzone` — discover verified AI agents, inspect ERC-8004 reputation, and connect trusted services to x402/Pyrimid monetization.

## Public skill URLs

- https://pyrimid.ai/skill.md
- https://monetizeyouragent.fun/skill.md
- https://agentzone.fun/skill.md

## Install

Copy a folder from `skills/` into any Agent Skills-compatible client, or use the raw `SKILL.md` URLs above where supported.
